01 Files and Search Data

ReplacePro is a desktop app for finding and replacing text across files. When you start a search or replacement, the app reads the names, paths, and contents of files in the folder you select, subject to your search filters and subfolder settings. It uses the search and replacement text you enter to find matches, display results, and make the changes you request. The files and paths you select may contain personal information.

✓

ReplacePro performs these operations on your computer. The app does not upload your files, file paths, search terms, replacement text, or results to MCHSofts or to an external service. It does not require a ReplacePro account or include advertising, usage analytics, or telemetry.

02 Settings, Backups, and Clipboard

ReplacePro stores your language preference in a settings file in your Windows user profile at:

%APPDATA%\MCHSofts\ReplacePro\settings.json

The app does not save a search or replacement history in this file.

If you enable Create .bak backups in the desktop app, ReplacePro can save a copy of the original file alongside the file it modifies. This option is off by default. Backup files may contain the same personal information as the originals and are stored as ordinary files, subject to the permissions and protections of the folder where they are saved. You can view or delete these copies in File Explorer and reset your language preference by deleting the settings file after closing the app.

If you choose Copy full path, ReplacePro writes the selected file path to the Windows clipboard. Clipboard history and syncing, when enabled, are controlled by your Windows settings. If you choose a network or cloud-synced folder, the permissions and syncing behavior of that location are controlled by the service or system that manages it.

!

Backup files may contain the same personal information as the originals. Protect the folder where they are saved, or delete any copies you no longer need.

03 Microsoft Store and Windows

Microsoft may process information when you use the Microsoft Store to download or update the app, or when you use Windows features. Microsoft handles that information under the Microsoft Privacy Statement.

04 Support and Privacy Requests

If you email MCHSofts, we receive your email address, the contents of your message, and any attachments you choose to send. We use this information to respond to your inquiry and follow up as needed.

!

Please remove sensitive information from any files, screenshots, or examples you send for support.

You can contact us to ask about, correct, or request deletion of personal information you provided directly to us. Files processed in ReplacePro remain under your control in the locations you select.
