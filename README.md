# MCH SOFTS

Site statique en français pour mchsofts.com. Servir ce dossier à la racine d’un serveur HTTP.

Pages : accueil, `/windows/`, `/SmartTypeAlert/`, `/android/`, `/extensions/`, `/Support.html`, `/privacy.html` et `/404.html`.

SmartType Alert est le seul logiciel actuel. Les rubriques Android et Chrome sont en attente de futurs produits. L’ancienne adresse `/fre.html` est conservée avec un message explicatif et exclue de l’indexation.

Pour ajouter un produit, créer sa page, ajouter sa fiche au catalogue et compléter `sitemap.xml`. Conserver la navigation commune. Le style est intégré dans chaque page pour permettre une ouverture directe des fichiers HTML ; `assets/site.css` en conserve une copie. Reporter les changements de style dans les pages concernées. Les liens relatifs fonctionnent aussi en prévisualisation locale.

Le fichier `files/stupe.exe` n’est pas présent. La page SmartType Alert affiche une information de disponibilité et un contact. Quand le fichier officiel sera fourni, l’ajouter et remplacer ce message par un lien vers `/files/stupe.exe`. La compatibilité Windows 11 reste à tester.
